# 글쓰기 쑥쑥! — Gemini 무료 등급용

학생이 사진을 촬영하거나 업로드하면 Gemini가 손글씨를 읽고, 학생이 전사문을 수정한 뒤 5가지 기준으로 평가합니다.

## 실행
1. Python 3.10 이상 설치
2. `pip install -r requirements.txt`
3. 환경변수 `GEMINI_API_KEY`에 **새로 발급한 키**를 저장하거나 Streamlit 배포 설정의 Secrets에 `GEMINI_API_KEY = "키값"`을 등록합니다. 키를 소스 코드에 직접 넣지 마세요.
4. `streamlit run app.py`
5. 학생에게 공개하려면 HTTPS를 제공하는 Streamlit Community Cloud 등 서버에 배포합니다. API 키는 서버 Secrets에만 저장하세요.

## 유의사항
- Gemini 무료 등급에는 모델/지역/계정별 사용량 제한이 있습니다. 모델 `gemini-2.5-flash`의 무료 이용 가능 여부를 AI Studio에서 확인하세요.
- 촬영한 이미지는 AI 분석을 위해 Google API로 전송됩니다. 학교 개인정보 지침과 보호자 동의 요건을 확인하고, 이름·얼굴·학교명이 찍히지 않도록 하세요. 특히 무료 API의 데이터 처리 조건을 사전에 확인하세요.
- 서버에 글/사진/평가 결과를 영구 저장하지 않는 시범 버전입니다. 학생은 결과를 파일로 내려받을 수 있습니다. 교사용 대시보드 및 평가 수정 기능은 아직 구현되지 않았습니다.
- AI 채점은 참고용이며 교사 확인이 필요합니다.
